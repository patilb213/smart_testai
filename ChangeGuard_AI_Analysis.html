Executive Summary

ChangeGuard AI is a scriptless test automation platform that records real user interactions, converts them into reusable test cases, and maintains a tamper-proof audit trail. Phase 1 (Foundation) is complete with working proof-of-concept, secure authentication, and blockchain-style audit logging.

What We Built

  • Records real user interactions (clicks, typing, form submissions) on any website
  • Automatically converts interactions into reusable test cases
  • Maintains a tamper-proof audit trail of every system action
  • Provides an intuitive web interface (no coding required)
  • Multi-strategy element locators (survives minor UI changes)

Why It Matters

Traditional Testing Problem: When websites change, automated tests break and need rewriting.

Our Solution: Tests survive minor UI changes because we capture elements using 4 different methods (ID, visible text, CSS selectors, position).

Audit Compliance: Every test creation/modification is logged with cryptographic proof (SHA256 hashing), perfect for regulated industries.

Core Features Explained

Feature 1️⃣: User Authentication

  • Signup: User creates account → Name + Email + Password hashed with bcrypt
  • Login: Email + Password → System generates JWT token (valid 8 hours)
  • Security: Passwords stored as hashes, never as plain text
  • Audit Log: Every login/signup recorded with timestamp + IP address

Feature 2️⃣: Test Recording (60-Second Workflow)

  1. User enters test name + target URL
  2. System launches browser in maximized window
  3. JavaScript injects event listeners for: click, input, select, submit
  4. User interacts with website (clicks, typing, form submission)
  5. Each action captured with 4 locator strategies:
    • Element ID (most specific)
    • Element Name attribute
    • Visible text (human-readable)
    • CSS selector (fallback)
  6. Human-readable descriptions generated (e.g., "Clicked button 'Submit Order'")
  7. After 60 seconds, recording stops and test case automatically saved

Feature 3️⃣: Tamper-Proof Audit Trail

Every important action creates an immutable log entry using blockchain-style hashing:

Log Entry Structure:

  • Action type (USER_LOGIN, TEST_CASE_CREATED, TEST_STEPS_SAVED)
  • User email
  • Entity type & ID
  • Before/After state snapshots
  • IP address
  • Timestamp
  • Current entry hash (SHA256)
  • Previous entry hash (blockchain chain)

Why? If someone tries to delete or modify an old log entry, the hash chain breaks and tampering is detected. This meets compliance requirements for SOX, HIPAA, PCI.
